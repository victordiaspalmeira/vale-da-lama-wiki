## 🎲 Sobre o Projeto

- **Sistema:** Pathfinder 2e Remaster
- **Cenário:** Vale da Lama — pântano de cogumelos, raízes colossais e deuses fúngicos
- **Tribo jogável:** Masca-Musgo (jovens iniciados prestes a realizar a Caçada Sagrada)
- **Gerador de site:** [Quartz v4](https://quartz.jzhao.xyz/)
- **Hospedagem:** GitHub Pages (build automático via GitHub Actions)

---

## 🛠️ Como Testar Localmente

```bash
# Instalar dependências
npm install

# Build do site
npm run build

# Servir localmente (acessar http://localhost:8080)
npm run serve
```
